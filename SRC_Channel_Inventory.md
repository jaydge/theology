## Method

1. **Source data.** `channel_videos.tsv` (369 lines incl. header = 368 data rows; columns `video_id, duration_seconds, upload_date, title, channel_code, channel_handle, source_tab`) and `channel_metadata.jsonl` (364 records; `video_id, upload_date, duration, title, description, view_count, channel`) were pulled by JD via `tools/` scraping. **4 of the 368 TSV video IDs have no corresponding JSONL metadata record** — see the note below. The TSV's own `upload_date` column is `NA` for all 368 rows (not populated at scrape time); the `Upload date` column below is backfilled from the JSONL where a record exists, and reads `unresolved` for the 4 gap IDs.
2. **Exact-ID matches (Files 27-34).** These eight Files' provenance already carries a recoverable YouTube video ID (via each source's own `-meta.json`, per `SRC_Manifest.md`'s Files 27-34 registration), and `SRC_Manifest.md` already records a File number and finding range for each. Matched here on strict video-ID equality. Marked `INGESTED`.
3. **Inexact title matches (Files 1-26).** These Files predate the `-meta.json` intake procedure and carry no recorded video ID — only a working title (sometimes a raw filename or guest surname). Each candidate File title/guest-name was searched against all 368 TSV titles; where the JSONL `upload_date` also independently corroborated the File's own recorded recording-date evidence (a second, structurally-independent check, not just a title string match), the match is recorded `INGESTED (inexact title match)`. Where a File's own internal session-numbering conflicts with the channel's own title-numbering (Files 11 and 12 — see below), or where a File spans multiple sessions and cannot map 1:1 to a single video (Files 1, 2, 4, 8, 9), no match is recorded and the row is left blank — see the Step-5b tally below for the full breakdown of matched / ambiguous / no-candidate outcomes.
4. **Category declines.** For the remaining videos (368 minus the 27 matched above), an automated classification pass reviewed title (and description, where JSONL metadata exists) against ten known decline categories from the prior ~120-video triage. Only unambiguous matches were marked `DECLINED`; all doubtful cases were left blank. See tally below.
